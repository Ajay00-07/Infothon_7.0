## 📌 About the Project

**Infothon 7.0** is the official web platform for a 10-hour national-level
hackathon organized by the Department of Information Science and Engineering
(ISE) at Vidyavardhaka College of Engineering (VVCE), Mysuru.

The website serves as a central platform for participants, students,
sponsors, and visitors to explore hackathon information, discover problem
statements, follow event updates, learn about the organizing team, and
access registration resources.

The website is designed with a modern, futuristic interface that combines
dark visuals, neon-green accents, subtle glassmorphism, and interactive
animations.

### 🎯 Objectives

- Provide a centralized source of official hackathon information.
- Present hackathon themes and problem statements.
- Communicate important deadlines and event announcements.
- Showcase sponsors, contributors, and the organizing team.
- Provide convenient access to registration and participant resources.
- Deliver a responsive and engaging experience across devices.

## 🚀 Getting Started

Follow these instructions to run the project locally.

### Prerequisites

Install the following tools:

- [Node.js](https://nodejs.org/) — Use a version compatible with the project dependencies.
- npm — Included with Node.js.
- Git — To clone the repository.

### 1. Clone the Repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

Navigate into the project directory:

```bash
cd Infothon_7.0
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the Development Server

```bash
npm run dev
```

Vite will display a local development URL in your terminal, usually:

```text
http://localhost:5173/
```

Open that URL in your browser.

### 4. Build for Production

```bash
npm run build
```

The optimized production build will be generated in the `dist/` directory.

### 5. Preview the Production Build

```bash
npm run preview
```

## ☁️ Deployment

The project is configured for deployment on **Vercel**.

### Deployment Workflow

1. Push the approved project changes to the GitHub repository.
2. Import or connect the repository to Vercel.
3. Configure the project using the existing Vite settings.
4. Set the appropriate root directory.
5. Confirm the build command is `npm run build`.
6. Confirm the output directory is `dist`.
7. Deploy the project.
8. Verify the deployed website and custom domain.

### Custom Domain

The production website is available at:

**https://infothon.co.in/**

DNS records and domain verification should remain consistent with the
existing Vercel and domain-provider configuration.

### Single-Page Application Routing

If the application uses client-side routing, verify that the existing
`vercel.json` configuration supports direct navigation to nested routes.
